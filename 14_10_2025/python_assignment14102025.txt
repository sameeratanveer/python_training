1. Python Introduction: 
Python is a popular programming language, which is created by Guido Von Rossum in 1991. 

Features of Python:  

1. Simple and easy to understand 

2. Open source - code is available for community, and we can contribute to it.

3. Dynamically typed - No need to define and declare variable and the type of data it holds, because all the variables are created in runtime.

4. Interpreted - The bytecode representation of python program is executed by PVM (Python Virtual Machine) which is an interpreter (executes one instruction at a time and line by line)

5. Follows OOPS - Everything in Python is considered as Objects and classes.

6. Rich libraries - As it is open-source, the contribution and various libraries makes python scope available in multiple domains

7. Portable - Runs in all OS

8. Cross-platform - the compilation is done on Windows and the byte code from windows can be executed in Linux.


2. Execution order of a python file: 

Python file is stored by .py extension.  

And when we run the .py file, the first thing it happens is that Python compiler checks for the syntax errors and reports it. If no errors are found then python compiler represents the .py file in Bytecode representation which is .pyc file inside the __pycache__ folder. 

Once this Bytecode representation is made, then Python interpreter takes this bytecode .pyc file and executes it line by line and returns the result as output. 

3. Variable:  

Variable is a placeholder for a value inside a memory. We access the value stored in the memory using this variable concept just like a name for the space we are using in the memory.  


When naming a space and value inside the memory using variables, we need to follow some set of rules: 

Variable Naming Rules: 

1. Variable name can contain the combination of alphabets and numbers and _ but no other special characters are allowed. 

2. Variable name must start with letter or _ but not with number. 

3. Variable name must be non-keyword.  

4. Variable names are case-sensitive in Python that means var1 != Var1  

When working within a team, naming the variables should be meaningful. Just by looking at the name of the variable we should be able to understand what king of value is getting stored in this.  

And Naming conventions:  

When working in a team, we decide to follow the convention for naming the variables throughout the project with the same format. 

For this we have main 3 formats. 

1. Pascal Case Format : ex:  FirstName

2. Camel case format: ex:  firstName

3. Snake case format : ex:  first_name

Variable must reference to value and value must be referenced by a variable, if any violates, the reference count gets 0 and when the reference count is 0 then the garbage collector, a component of python that is responsible for memory management. This garbage collector deletes the value and variable and free ups the space.  

Hence this is the advantage of Python’s garbage collector. We dont need to keep track of used and unused variables, python’s garbage collector takes care of it, making the memory management, a tedious task easy for us.

-> Difference between tuple and list?
1. Lists are mutable, it means the length and the values inside the list can be changed, whereas tuple cant be done.
2. Lists have more methods than tuple
3. List is slow in performance because as list is dynamic in nature they are stored in dynamic memory and hence accessing and performance is complex and slow. Whereas Tuples are fixed in size and they are easy to access..
4. List takes more space than tuples
5. List is not hashable whereas tuples are

-> Why tuple is faster than list?
Tuples are stored in a fixed memory structure format, whereas lists are dynamic array that expands or shrinks. Hence, tuples dont require extra memory management hassle, hence they are fast!
