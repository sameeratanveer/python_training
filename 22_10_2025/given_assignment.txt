'''
3. Write a function:
def append_item(item, item_list=[]):
    item_list.append(item)
    return item_list

Call it multiple times and observe the output.
Explain why the list keeps growing.
Fix it by making the default parameter immutable.
'''

PROGRAM:

def append_item(item, item_list=[]):
    item_list.append(item)
    return item_list
print(append_item(1))
print(append_item(2))
print(append_item([1,3]))
print(append_item(2, [1,3]))

OUTPUT:
[1]
[1, 2]
[1, 2, [1, 3]]
[1, 3, 2]

EXPLANATION: 
Default value which is item_list = [] is created only once when the function is defined. Hence whenever item_list s not send as an argument in functional call it takes the default item_list which was created at the time function definition it is mutable and this is the reason why list keeps growing. 

In the last function call the passed argument is overwritten the default argument. Hence new list is used..

To fix this we have to change its mutability to immutable object, which can be achieved using None set to the list.

FIXED PROGRAM:

def append_item(item, item_list=None):
    if item_list is None:
        item_list = []
    item_list.append(item)
    return item_list
print(append_item(1))
print(append_item(2))
print(append_item([1,3]))
print(append_item(2, [1,3]))

# if item_list is not forwarded then a new list is created at every call.. 
OUTPUT:
[1]
[2]
[[1, 3]]
[1, 3, 2]

PROGRAM:

def student_profile(*courses, **details):
    print('Taken courses: ', end = '')
    for course in courses:

'''
8. Nested Functions and Scope (`global`, `nonlocal`)
Write a function:
count = 0
def outer():
    total = 10
    def inner():
        nonlocal total
        global count
        total += 5
        count += 1
        return total, count
    return inner()
Predict the output.
Explain what happens if you remove `global` or `nonlocal`.
'''

PROGRAM: 

count = 0
def outer():
    total = 10
    def inner():
        nonlocal total
        global count
        total += 5
        count += 1
        return total, count
    return inner()
print(outer())

OUTPUT:
(15, 1)

EXPLANATION:
count = 0 is a global variable that means it is accessed everywhere throughout the program only if there is no local variable with the same name in the scope of the block.
total = 10 is global for inner() but local for other part of the program. Same here we can use total in inner if there is no other variable with the same name. 
nonlocal total means we are accessible nonlocal variable which then again refers to the above block variables in this case we have outer() just above inner() an indeed it has total variable. Hence we can now access that as a local variable, edit it like that and use it just like local variable.
global count means we are accessing the global variable count.
so, 
1st time: total = 10
then inner function, we updated total value with the help of nonlocal keyword : total = 15
count global was 0 then we updated +1 then it is count = 1
And we are returning to the outer function this total and count, (15,1) 
And outer function is returning that only to our function call and we get the output as (15,1)

If we remove that, we will get error because we are incrementing the value whose initial value is unknown.. then all of them are local and their initial value is unknown so we cant increment that..
