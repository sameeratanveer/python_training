STRING SLICING AND INDEXING:

Index is the position of the character inside the string.
Index starts from 0 and the position increases by +1 

So, if the string is: 'Hello'
then,
H position is 0
e position is 1
l position is 2
l position is 3
o position is 4

Therefore length of 'Hello' is 5 that is last character position + 1

len() == position of last character + 1

Program:

sentence = 'Hello world! Welcome.'
print("Index of first character is: ", sentence[0])
print("Index of last character is : ", sentence[len(sentence)-1])
print("Index of e in the sentence is: ", sentence.index('e'))
print("Index of first letter of the substring 'Hello' in the sentence is", sentence.index('Hello'))

Index of first character is:  H
Index of last character is :  .
Index of e in the sentence is:  1
Index of first letter of the substring 'Hello' in the sentence is 0

SETS: 

'''
Sets: set is a datatype in python that stores multiple values or elements in a single variable or container

Set is unorders, unchangeable, and unindexed datatype that means the elements inside the set cant be accessed using indexes
Set is mutable but the elements inside it can not be changed because we cant use index to specify the element and then change that element. either we add the new value and delete the old value but we cant access the old value and mutate it with the other value.
'''
